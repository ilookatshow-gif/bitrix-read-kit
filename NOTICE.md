# Provenance and limits / Происхождение и ограничения

Author / Автор: **Дмитрий Лукашов (Dmitry Lukashov)**.

This standalone module was created from scratch for the Lookatshow open-module
program on 10 October 2026 with AI-assisted development and human-owner direction.
No private Lookatshow Harness source, client correspondence, credentials or CRM
exports were copied into the package. The included example records are synthetic.
The code and documentation in this package are offered under the MIT license.

Bitrix24's official REST documentation informed the request contract. The package
does not include or relicense Bitrix24 source code, SDKs or branding assets.
Bitrix24 is a third-party product; this module is not an official Bitrix24 product
or endorsement. Python's standard library is required; no bundled third-party
Python dependencies are included.

Это самостоятельный CLI, а не MCP-сервер и не закрытое ядро Lookatshow. Бесплатные
установка, учебный пример и локальный анализ не требуют покупки ядра. Настоящий
портал, OAuth, агентский клиент, Windows и Linux этим локальным этапом не проверены.
Тесты с подставными HTTP-ответами не подтверждают доступ к реальной CRM.

The original CI workflow references GitHub's checkout v7.0.1 and setup-python
v7.0.0 actions pinned to full commit hashes. Both upstream projects are MIT
licensed; their code is not vendored here. Sources:
https://github.com/actions/checkout and https://github.com/actions/setup-python .
Selected CI environments and the local acceptance are separate observations;
consult the exact run status instead of treating a YAML file as execution proof.

The optional onboarding command displays the author's channel and the relevant
training / implementation offers once per explicitly selected local state
directory. Analysis output contains no recurring advertising. No hidden telemetry
is implemented. CRM identifiers remain private, linkable data even without names;
the module must not be described as anonymizing a real capture.
